# Footballer Analyzer · 评委演示

**访问：https://allwayso.github.io/Footballer-Analyzer-Demo/**

真实预计算结果，仅展示 `barca_girona_25m00s` 的源帧 `[0,1503)`，60.12 秒。

- 视频与识别结果：视频播放、精确逐帧、人物框与球场位置联动。
- 人工校验记录：场内片段、人工身份、有效融合与操作历史（只读）。
- 跑动分析：轨迹回放、热图、速度、对比及 CSV / JSON / PNG 导出。

本素材有19名球员与1名裁判的人工身份，没有足球追踪数据。名称数字为人工身份编号，不代表球衣号码。

**仅统计本片段，米制精度尚未独立验证。** 缺口不补点、不补算距离。

## 离线备用

下载本仓库 ZIP 并解压，可直接打开 `index.html`；推荐双击 `preview.cmd`（需要 Python 3）。预览器自动选择空闲的本机端口，不需要推理服务、模型或GPU。完整离线包应包含全部1503张帧图和 `video.mp4`。

## 更新

从主项目运行 `scripts/export_static_demo.py --run <运行目录> --report <指定可视化报告目录> --output <全新目录>`。报告必须与当前标注快照一致，工具会拒绝过期输入。

整体替换展示文件与帧图，检查 `export-validation.json` 后提交到本仓库 `main`。Actions 会自动发布。不要上传原始运行配置、模型或机器路径，也不要只替换视频而沿用旧数据。

页面使用相对资源链接，初次访问仅按需加载当前及相邻帧图片。公开数据摘要见 `input-hashes.json`；所有页面使用相同输入快照。
